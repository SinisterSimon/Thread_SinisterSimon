Thread · portfolio project

Counting every sale after a message overstated what the messages caused by 1.6–4.7×.

Thread is a test lab for AI sales agents. Simulated shoppers with real objections talk to pluggable agents, every conversation is scored, and a randomized holdout group measures what each agent really adds, then checks that estimate against the simulator's hidden truth.

See the experiments Read the findings

The demo simulates a 180-day store and runs three agents with a 50% holdout. It takes about a minute.

Five simulated 180-day stores, 50% holdout, offline mode with scripted agents. Method and full results in the findings report.

How it works

  1. Simulate a store. Checkouts, abandonments and shoppers who come back on their own, with the truth recorded but hidden.
  2. Split at random. A share of abandoned checkouts gets no message. That holdout is how a real store measures lift.
  3. Let agents talk. Each agent texts five kinds of shopper: price-sensitive, unsure about fit, worried about delivery, just browsing, frustrated.
  4. Score and measure. Rules plus an AI judge rate every chat; the holdout estimate is compared with the true lift.

Under the hood

Python 3.12 · FastAPI · Postgres (Neon) · SQLAlchemy + Alembic · Claude models behind one LLM layer, with a free offline mode · guardrails outside the model · Langfuse tracing · background worker · CI on GitHub Actions · deployed on Render.
